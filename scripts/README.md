# scripts

Calx: building and testing everything, releases, the install script for servers, and generating the design tokens. Run each from the repository's root.

- `calx scripts/check.calx` checks and tests all of loom's Calx code, as CI does: that the Calx is the pinned one, formatting, that every file builds, every file's tests, the design tokens, and the protocol tests, several at once, with one that fails run again alone.
- `calx scripts/calx_pin.calx` says whether the Calx on PATH is the one loom is pinned to in `.calx-version`, which CI, the release and the Docker image install (`.github/actions/calx`), and how to install it: `calx update --to VERSION`. Calx keeps every build in a release of its own, `vVERSION`, which is where they install from. `bump` pins the Calx on PATH: it checks that its release has it and its toolchain for every system, and writes `.calx-version`.
- `calx scripts/ci_times.calx` says how long CI's last runs took, queued to finished, and each job's wait for a runner and its own time, at the middle and the 95th percentile. A number after it says how many runs.
- `calx scripts/icons.calx` makes the Mac and iPhone app icons from the PNGs in `design/logo/png`.
- `calx scripts/wordmark.calx` outlines the wordmark into `design/logo/wordmark.svg`.
- `calx scripts/tokens.calx` generates the design tokens from `design/tokens.toml` into `design/generated/`. `--check` fails if they're out of date.
- `calx scripts/emoji.calx` fetches and vendors the built-in emoji (PLAN.md, "Emoji"): Twemoji's SVGs into `design/twemoji/` with their CC-BY 4.0 licence, and the names, groups, keywords and skin tones into `shared/emoji/emoji.tsv`, from Unicode's emoji-test.txt, CLDR's English annotations and gemoji, with their licences. `--twemoji`, `--emoji`, `--cldr` and `--gemoji` (a commit) name other versions than the ones it pins.
- `calx scripts/ios.calx` builds the core for the iPhone app as `build/ios/LoomCore.xcframework` and generates `ios/Loom.xcodeproj` from `ios/project.yml`, on a Mac. `--sim` builds for the simulator alone, and `--sample` makes the project without the core ([ios/README.md](../ios/README.md)).
- `calx scripts/release.calx` makes and checks releases (PLAN.md, "Updates and versions"): `sign` writes and signs `manifest.json` with the release key, `verify` checks it, `pack` puts `loom.exe` into loom's installer under a signed header, and `bridge` writes the `update.json` v0.1's own updater reads, signed with v0.1's key, to move v0.1 over. `key` and `seed` make the release key and give it for the CI secret. The comment at its top says what each takes.
