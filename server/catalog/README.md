# Spools' logos

The marks Spools shows on a catalog entry's badge until the server gives an icon of its own (`server/catalog.calx`, `logo`). Each is one colour, drawn in `currentColor`, and goes to the apps as the entry's `icon_svg`. Only `role`, `title` and the fill changed from the source.

| File | Source | Licence |
|---|---|---|
| `acta.svg` | Lucide's "layers", the glyph Acta's cards in messages draw | ISC |
| `github.svg`, `notion.svg`, `linear.svg`, `vercel.svg`, `cloudflare.svg`, `home-assistant.svg` | [Simple Icons](https://simpleicons.org) 16.38.1 (`homeassistant.svg` for Home Assistant) | CC0 1.0 |

T3 Code and Playwright have no single-colour mark with a free licence, so their badges keep their initial. The names and marks are their owners' trademarks.
