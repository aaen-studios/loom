# Spools' logos

The marks Spools shows on a catalog entry's badge until the server gives an icon of its own (`server/catalog.calx`, `logo`). Each is one colour, drawn in `currentColor`, and goes to the apps as the entry's `icon_svg`. Only `role`, `title`, the size and the colour changed from the source.

| File | Source | Licence |
|---|---|---|
| `acta.svg` | Acta's own mark, `src/app/icon.svg` in [Acta's repository](https://github.com/ellipog/acta) at 599c2d5 (the same mark as acta.aaenz.no's favicon) | Aaen Studios' own, used with its permission |
| `t3.svg` | T3 Code's "T3" mark, `assets/prod/logo.svg` in [pingdotgg/t3code](https://github.com/pingdotgg/t3code) at d249e62, without its black square | MIT (the repository's licence) |
| `github.svg`, `notion.svg`, `linear.svg`, `vercel.svg`, `cloudflare.svg`, `home-assistant.svg`, `gmail.svg`, `discord.svg` | [Simple Icons](https://simpleicons.org) 16.38.1 (`homeassistant.svg` for Home Assistant) | CC0 1.0 |

Playwright has no single-colour mark with a free licence, so its badge keeps its initial. The names and marks are their owners' trademarks.
