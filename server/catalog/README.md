# Spools' logos

The marks Spools shows on a catalog entry's tile and in Installed (`server/catalog.calx`, `logo`, and `KNOWN` for a server that isn't an entry, by its host or its name). Each is one colour, drawn in `currentColor`, and goes to the apps as the entry's `icon_svg`. Only `role`, `title`, the size and the colour changed from the source.
