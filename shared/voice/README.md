# Voice's logos

The marks Settings › Voice shows on an engine's tile and the voice_setup card shows on its own (`shared/voice.calx`, `ENGINES`, each engine's `mark`). Each is one colour, drawn in `currentColor`, and goes to the apps as the tile's `icon_svg`. Only `role`, `title`, the size and the colour changed from the source.
