Loom, round 4

Round 3, simplified further and filled out. Open this file in a browser: the threads move.

  • The sidebar is only agents, with a Pinned group on top. Each agent is one long, ongoing chat, like messaging a bot. "Start fresh" in the agent's menu clears its context.
  • The composer is only a text box, attach and send. The agent's menu, its program and its permission mode sit in the chat's header.
  • A thread says what its agent is doing, with eight states and a few looks, below.

Threads

An agent's thread is the only colour in the app. Its state is in how it moves, so it reads the same in the sidebar (26 px), the header, beside a reply, and large in the agent's own page. All of them respect "Reduce motion", which keeps the shapes and stops the movement.
